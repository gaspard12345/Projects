# Holdings pipeline (synthetic data)

![tests](https://github.com/gaspard12345/Projects/actions/workflows/tests.yml/badge.svg)

**👉 [See the results: DEMO.ipynb](DEMO.ipynb)**

Practice project with fake data: loading fund holdings files from two asset managers, checking them, enriching them with reference data, and producing an exception report. All rules are covered by pytest tests, which run automatically at every change with GitHub Actions.

Reconciliation tolerance: EUR 0.01
